# GitHub Commit Plan

The assignment requires at least 10 genuine, incremental commits. Do not
create fake history or make ten identical commits immediately before
submission. Make each commit after a real step, push them regularly, and use
the actual dates of your development.

Suggested development sequence:

1. `Create Android Studio Java project skeleton`
2. `Add SQLite schema for pantry and recipes`
3. `Seed initial recipe collection`
4. `Implement pantry item model and database CRUD`
5. `Build pantry RecyclerView adapter and list screen`
6. `Add validated ingredient create and edit form`
7. `Add delete confirmation for pantry items`
8. `Implement strict ingredient and quantity matching`
9. `Add suggested recipes and recipe detail Activities`
10. `Add settings screen and bottom navigation`
11. `Improve empty states and mobile layouts`
12. `Document setup and assignment demonstration flow`

Before submission:

- Create a public GitHub repository.
- Push the project source.
- Make genuine commits while developing or improving the project.
- Add the repository URL to the report.
- Take a screenshot of the commit history for the report/video.
